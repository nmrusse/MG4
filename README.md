# MG4
## Devlog
The FloatAnimation script makes the fish food move up and down The Start() method begins when the script runs and it triggers the timer. Meanwhile, the Update()feature works in  every frame, moving the food up and down consistently. The _up variable works as a true or false mechanism that decides if the food should move up or down. The _timer variable decides when to change the foods up and down direction.
